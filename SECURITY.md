# Security Policy

Prebid.org takes the security of its open-source projects seriously. If you believe you have found a vulnerability in Prebid Cache, please report it privately so the maintainers can investigate before information is disclosed publicly.

## Reporting a Vulnerability

**Do not disclose security vulnerabilities in public GitHub issues or pull requests.**

Use the [Prebid Cache security page](https://github.com/prebid/prebid-cache/security) to check for private reporting options. You may also email **security (at) prebid.org**. If you cannot submit a report through GitHub, use email instead.

If you do not receive an acknowledgement, follow up by email to confirm that your original report was received.

To help the maintainers assess and reproduce the issue, please include, when available:

- The type of vulnerability and its potential impact
- The affected version, tag, branch, or commit
- Relevant file paths and code locations
- Any configuration or environment needed to reproduce the problem
- Clear, step-by-step reproduction instructions
- A proof of concept, shared privately, if appropriate
- How the issue could be exploited and any observed consequences

Please coordinate public disclosure with the maintainers after the report has been reviewed.
